## 职责定义

**本命令只做诊断，不执行任何写入。**

如果你在本命令运行结束后希望执行安装，请使用 `/auto-deploy-stack`。

---

## 执行步骤

1. 调用 `stack-auditor` 子 agent，触发 `environment-audit` skill，扫描当前项目级与全局级配置
2. 调用 `load_stack_registry` 加载推荐组件清单
3. 逐项对比现有环境与清单，输出三类结论：
   - **可部署**：已具备的能力，无需额外操作
   - **需补装**：缺失的关键/建议组件，给出优先级（必装 / 强烈建议 / 可选）
   - **需清理**：与保研项目冲突或重复的组件，给出清理建议
4. 调用 `build_install_confirmation` 生成安装确认问题，向用户展示：
   - "是否现在进入 `/auto-deploy-stack` 执行安装？"
   - "是否只安装最小集（Playwright MCP + GitHub agent）？"
   - "是否暂时保持轻量环境？"
5. **等待用户回答，不得自动触发写入**

---

## 输出格式

```
## 部署前诊断

### 可部署
[列出已有能力]

### 需补装
| 组件 | 优先级 | 原因 |
|------|--------|------|
...

### 需清理
[列出冲突/重复项，或"无"]

---

### 确认问题
[由 build_install_confirmation 生成的用户确认问题]

提示：若需执行安装，请运行 /auto-deploy-stack
```
